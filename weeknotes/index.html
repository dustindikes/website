Week Notes

Each week I collect the most interesting infosec content I've come across. They contain a running list of articles I've read, videos I've watched, podcasts I've listened to, and other resources worth checking out. These notes serve as both a personal archive and a curated snapshot of what's been happening in the security world each week.
